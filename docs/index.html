Workout import helper

Turn an old training spreadsheet into a workout-backup.json the app can import, with a review step that catches the errors the app cannot report.

Runs on this page. No request, no upload, no account, and no training data is stored. The only thing remembered between visits is the exercise-name mapping.

Source

Drop JSON, CSV or TSV files here — or a Waistline backup

One or several. Each is read on this page with FileReader and never uploaded; each becomes a list below.

Loaded lists

Each file is one list, with its own revision: session and set ids derive from it. Re-importing the same revision is a no-op. The app merges and never overwrites, so correcting a session that already imported means deleting it in the app, raising that list's revision, and importing again.

The app's seeded library is already loaded, so a name links to its permanent slug. An export adds your own exercises and the dry-run comparison against what is already imported. Export once from the app: Settings → Export.

Exercise mapping

Type in Linked to to search the library by name; the list is alphabetical, and Create new exercise keeps the sheet's own name. The unit is a property of the exercise name. The mapping, and only the mapping, is kept in this browser's local storage; a button below forgets it. A name matching only a deleted library row creates a new exercise rather than bringing the deleted one back.

The prompt for a model

Paste this into a model together with the spreadsheet. It asks for flat rows and refuses to let the model invent ids, timestamps, grams or half-points.

If you use a hosted model, the spreadsheet left your machine before this tool saw it. The tool's own no-request guarantee does not cover that step.
